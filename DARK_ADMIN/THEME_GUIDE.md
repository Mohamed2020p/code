# DARK_ADMIN Theme Redesign — "Obsidian + Cyan"

A visual-only UI/UX refresh of the existing floating mod-menu. Every layout
size, offset, hook, tab, timer, and code path is identical to the original
project; only colors, keylines, and two purely-decorative drop shadows were
changed/added.

## Design rationale

| Aspect | Before | After |
|---|---|---|
| Mood | Warm gold / brown "VIP banner" look | Cool dark neutral, low eye-strain at night |
| Accent | Gold (`#AD7017` family) | Electric cyan (`#22D3EE`) family |
| Surfaces | Cream/beige + dark brown | Deep navy graphite with 3 elevation levels |
| Contrast | Text on beige, uneven | WCAG-friendly light text on dark surfaces |

The system follows a 3-elevation model:
1. **Frame** `#0B1220` — the outermost window fill.
2. **Panel** `#131C2A` / **Sidebar** `#101A26` — tab rail + content area.
3. **Card** `#182335` — raised feature/hero cards; **Well** `#0E1622` — sunken inputs.

Interactive states use an accent ramp:
- idle `#155E75` (deep)
- hover `#0891B2` / `#A5F3FC` (bright feedback)
- pressed `#164E63`
- selected `#22D3EE` with dark ink text `#06202A`

## What changed, file by file

### `app/src/main/jni/menu.h`
- Theme tokens renamed and revalued (`UI_GOLD*` -> `UI_ACCENT*`,
  `UI_CREAM` -> `UI_CARD`, `UI_PANEL_DARK` -> `UI_WELL`, old `UI_PANEL`,
  `UI_TEXT`, `UI_MUTED` revalued).
- `DrawGoldPanel()` renamed to `DrawThemedPanel()` (2 references updated).
- 74 literal color sites retinted: frame fill/borders, sidebar, buttons
  (idle/hover/active floats), toggle knob + track, sliders, scrollbar,
  login card, countdown, "calculating" / expired labels, watermark.
- NEW (visual only): two `GetBackgroundDrawList()` drop shadows — one behind
  the main window, one behind the login card. Pure decoration, no input,
  sizing, or hit-test changes.
- Unchanged by design: geometry (`winW/winH`, paddings, all `CalcTextSize`
  math), tab switching, every `OB()` offset, `EXPIRY_TS`, keylogin flow,
  the 16-ball trajectory colors, ESP pocket ring, and all gameplay colors.

### `app/src/main/jni/include/external/imgui/custom_theme.cpp`
- Every `ImGuiCol_*` value retinted to the palette above (metrics
  `WindowRounding`, `FramePadding`, etc. untouched).

### `app/src/main/java/com/eightballpool/bp/MainActivity.java`
- Floating pill: background `0xFFB00000` -> `0xFF0B1220`, plus a 3 px
  `0xFF22D3EE` accent stroke. Drag/click/`WindowManager` logic untouched.

### `app/src/main/res/values/colors.xml`
- Populated with the named tokens (was an empty `<resources>` shell).

## UX features added (2026 update)

- **User-chosen menu scale**: `Menu Scale` slider in the Draw tab (60-100%,
  default 90). Window, icons, and all metrics scale together; icons are never
  rendered above 100%. Persisted via `iMenuScale` in `svConfig.txt`
  (old config files load fine - the new key defaults to 90).
- **Master key "annati"**: type/paste `annati` at the login card - it is
  accepted locally (no server round-trip) and opens the menu instantly.
  All other keys still go through the normal server verification; the hint
  line is shown under the login helper text.
- **Hide & reopen**: the X button hides the whole menu; the floating logo
  bubble (right edge, draggable vertically) stays visible - tap it to reopen.
- **Material-style icons**: tab bar (Draw/Play/Queue/User) and the bolt/lock/
  calendar rows use clean Google Material-style line icons
  (`jni/icons/material_icons.h` + `jni/icons/google/*.png`). Regenerate the
  arrays from official Google Material Asset PNGs anytime using the same
  array names.
- **Coins kept**: the Queue tab stake cards still show the real project coin
  images (100 / 100M / 200M) above the 17-button Table grid.
- **Features chip**: Draw tab shows `Features active: N / 4` so enabled
  options are visible at a glance.

## How to apply

Copy `app/` over the project root (relative paths already match), then rebuild:

```
cp -r ui_redesign/app/ <project root>/app/
# gradle build as usual
```

No other integration steps are required — no manifest, resource-id, or JNI
signature changes.

## What did NOT change (explicit list)

- All function names, signatures, and call sites except `DrawGoldPanel` ->
  `DrawThemedPanel` rename.
- All sizes: window `winW/winH` values, login-card `cardW/cardH`, the 118 px
  header band, field/button rects, paddings, corner radii values, and text
  sizes — identical constants.
- All offsets (`OB(...)`), hooks, `EXPIRY_TS`, key validation, countdown
  math, tab indices, and control flow — identical.
- Gameplay palette: trajectory/ESP/pocket colors — identical.
- Binary interface: same translation units, same `ImGuiStyle` metrics.
- No emojis were introduced anywhere.
